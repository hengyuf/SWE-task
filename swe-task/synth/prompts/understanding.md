# Understand {{repo}}

Study the repository checked out at /app in the sandbox (inspection only: do not modify it) and write
`understanding.md` in this directory for engineers who will design feature-level tasks in it:
1. Purpose and architecture overview.
2. Module map: for every top-level package or module, its responsibility, key files, main public APIs or entry
   points, the test files that cover it, and the command that runs just those tests.
3. Cross-module data and control flows that a new feature would usually have to touch.
4. Offline build and test commands, and anything slow or flaky.
